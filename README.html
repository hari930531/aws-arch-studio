AWS Arch Studio

Cloudcraft-Inspired 2D/3D AWS Architecture Designer, Real-Time FinOps Cost Optimizer & Multi-File Terraform Code Generator for VS Code

VS Code Extension v0.1.0 TypeScript 5.x + React 18 AWS Regional Pricing & FinOps Terraform HCL Generator MIT License

1. Key Features

2D Drag-and-Drop Architecture Canvas

Model AWS topologies using Regions, Availability Zones, VPCs, Subnets, Security Groups, EC2, RDS, S3, ALB/NLB, CloudFront, WAF, Route 53, KMS, Secrets Manager, and API Gateway.

2D-to-3D Isometric Visualization

Toggle seamlessly between flat 2D schematic view and isometric 3D infrastructure rendering with animated directional traffic links.

Real-Time Cost & Budget Gauge

Calculates per-service and total monthly USD estimates across AWS regions (ap-south-1, us-east-1, etc.) against a live budget threshold.

FinOps 1-Click Optimization Engine

Detects storage (gp2 to gp3), Graviton (t4g), and off-hours scheduling savings, updating both the diagram and Terraform output in one click.

Multi-File Terraform IaC Export

Generates modular HCL files (provider.tf, variables.tf, main.tf, outputs.tf) with dynamic AMI/AZ data sources and VPC/SG dependencies.

Blueprint Persistence & SVG Export

Save and reopen diagrams as .arch.json files with recent-file history, or export crisp .svg vector diagrams for documentation.

2. System Architecture Diagram

AWS Arch Studio uses a Dual-Process VS Code Architecture: a Node.js Extension Host for native OS/file-system operations and a sandboxed React Webview UI communicating over typed JSON messages.

4. Step-by-Step Build Process (From Scratch to Packaging)

Phase 1: Extension Host & Webview Scaffolding

  1. Configured package.json to register awsArchStudio.open and aws-arch-studio.open under the VS Code Command Palette.
  2. Used esbuild (npm run compile) to bundle src/extension.ts into a fast CommonJS entry point (dist/extension.js).
  3. Built webview-ui/ using React + TypeScript + Vite (npm run build) to emit static assets into webview-ui/dist/.

Phase 2: 2D/3D Canvas & State Management

  1. Created useArchStore.ts to store AWS nodes, connection edges, target region, and monthly budget limits.
  2. Implemented hierarchical container nesting (Region → AZ → VPC → Subnet → EC2/RDS) in Canvas2D.tsx and projected the identical state into an isometric 3D scene in Canvas3D.tsx.

Phase 3: Cost Calculator & FinOps Engine

  1. Built costCalculator.ts using regional unit pricing to update monthly spend dynamically as components are added or resized.
  2. Implemented finopsRules.ts to surface actionable cost optimizations (EBS gp2 → gp3, Graviton t4g migration, off-hours scheduling) with 1-click state updates.

Phase 4: Multi-File Terraform HCL Generation

  1. Built src/services/terraformGen.ts to generate four clean Terraform files: provider.tf, variables.tf, main.tf, and outputs.tf.
  2. Connected VS Code's native folder dialog (showOpenDialog) to save all generated .tf files and open main.tf side-by-side (ViewColumn.Beside).

Phase 5: Slim .vsix Packaging & Installation

  1. Added .vscodeignore to exclude node_modules/, raw .ts/.tsx files, and source maps—shrinking the packaged extension from 282 MB down to 481 KB (19 files).
  2. Compiled, packaged, and installed the extension into VS Code: 
    npm run compile
npm run build
npx @vscode/vsce package --allow-missing-repository
code --install-extension aws-arch-studio-0.1.0.vsix

5. Installation & Usage Workflow

Install from .vsix Package

  1. Download aws-arch-studio-0.1.0.vsix from GitHub Releases.
  2. In VS Code, press Ctrl + Shift + X → click ... → Install from VSIX... → select aws-arch-studio-0.1.0.vsix.
  3. Press Ctrl + Shift + P and run AWS Arch Studio: Open Architecture Designer.

Run from Source

git clone https://github.com/hari930531/aws-arch-studio.git
cd aws-arch-studio
npm install
cd webview-ui && npm install && cd ..
npm run compile && npm run build

Press F5 inside VS Code to launch the Extension Development Host.
